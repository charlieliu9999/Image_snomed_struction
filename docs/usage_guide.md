# User Usage Guide

This guide provides step-by-step instructions on how to use the web interface of the Imaging Report Analysis Tool.

## 1. Accessing the Application

1.  **Ensure the Backend is Running:** Before you start, make sure the backend server is running as described in the [Backend Setup Guide](./backend_setup.md). By default, it runs at `http://127.0.0.1:5000`.
2.  **Open the Frontend:** Open the `imaging_report_frontend/index.html` file in your web browser. For the best experience, especially to avoid potential issues with API calls, it's recommended to serve the frontend using a simple HTTP server as described in the [Frontend Setup Guide](./frontend_setup.md) (e.g., by running `python -m http.server 8080` in the `imaging_report_frontend` directory and navigating to `http://127.0.0.1:8080`).

You should see the main page titled "Imaging Report Analysis Tool".

## 2. Submitting a New Report for Analysis

The main view ("New Report" view) allows you to input the details of an imaging report.

1.  **Fill in Patient Information (Optional):**
    *   **Patient Age:** Enter the patient's age (e.g., "55").
    *   **Patient Sex:** Select from the dropdown ("Unknown", "Male", "Female", "Other").

2.  **Fill in Report Details (Required fields are marked with * in the application if applicable, but generally, provide as much detail as possible):**
    *   **Chief Complaint (Optional):** Enter the patient's main complaint (e.g., "Persistent cough for 2 weeks").
    *   **Examination Requested: \*** Enter the name of the examination performed (e.g., "Chest X-ray AP and Lateral").
    *   **Imaging Findings: \*** This is a crucial field. Copy and paste the detailed findings described in the imaging report here.
    *   **Diagnostic Impression: \*** Copy and paste the diagnostic impression or conclusion from the report.

3.  **Submit the Report:**
    *   Click the "Submit Report for Analysis" button.

## 3. Understanding Processing Status

After submitting a report, the interface will provide feedback on the processing status:

*   **"Submitting report..."**: Displayed briefly while the frontend sends the data to the backend.
*   **"Checking status for Report ID: {your_report_id}... (Status: POLLING_STATUS/PENDING/PENDING_CONFIRMED)"**: The backend has accepted your report and is now processing it. The frontend will automatically check for updates every few seconds. The specific status message might vary slightly as it polls.
*   **"Report ID: {your_report_id} | Status: COMPLETED"**: Processing is finished successfully. The results will be displayed below.
*   **"Error: {error_message}"**: If an error occurs during submission or processing, a message will describe the issue. Examples:
    *   `Error: Failed to submit report. Please try again.`
    *   `Error: Processing failed for an unknown reason.` (If backend processing fails)
    *   `Error: Failed to poll report status.` (If frontend cannot reach backend for status updates)

## 4. Viewing Analysis Results

Once the `processing_status` is "COMPLETED", the analysis results will appear below the status message. The results section includes:

*   **Patient & Report Information:** A summary of the input patient data, examination type, and the LOINC code identified for the examination (with its Chinese translation).
*   **Reported Information:** The raw text you entered for Chief Complaint, Imaging Findings, and Diagnostic Impression.
*   **Gemini LLM Analysis:**
    *   **Summary:** A summary of the report generated by the Gemini language model.
    *   **Key Findings:** A list of key findings extracted by Gemini.
*   **SNOMED CT Analysis (Tree):**
    *   A hierarchical tree display of medical concepts identified in your report text.
    *   Each entry shows:
        *   **Term (English)** (SNOMED CT Code) - *Chinese Translation*
    *   The tree structure shows relationships (e.g., sub-types, findings related to specific anatomical locations if the backend's SNOMED CT logic supports such detailed relationship extraction - current version shows 'is-a' hierarchy).

## 5. Using the History View

The tool keeps a history of submitted reports and their analyses.

1.  **Access History:** Click the "View History" button in the header.
2.  **Browse History:**
    *   The history view lists previously submitted reports, showing the Report ID, Timestamp, basic patient info, examination, and processing status.
    *   Reports are listed with the newest first.
    *   If a report is still "PENDING", it will be indicated.
3.  **View Details of a Historical Report:**
    *   For reports that are "COMPLETED" or "FAILED", a "View Details" button is available.
    *   Clicking this button will take you back to the main view and display the full analysis results for that selected report, similar to how they appear after a new submission completes.
4.  **Return to New Report Form:** Click the "New Report" button in the header to go back to the main input form.

This guide should help you effectively use the Imaging Report Analysis Tool. For a more in-depth look at an example, please see the [Case Study](./case_study.md).
